# IT-словарь · тренажёр

Личный тренажёр, чтобы держать в голове современную IT-терминологию: AI и вайбкодинг, архитектура (ADR, RFC…), DevOps и Git, SQL, Supabase и RLS, React, безопасность, роли (CEO, CTO, HRD…), бизнес-метрики и рабочий сленг.

**~750 терминов → ~1800 вопросов**, которые собираются автоматически:

- **Что означает** — термин → смысл
- **Как называется** — смысл → термин
- **Расшифровка** — аббревиатура → полное название
- **Практика** — ручные вопросы на понимание (SQL, RLS, React, AI) с объяснениями

Режимы: разминка на 10 вопросов (сначала слабые места), экзамен по теме (20 вопросов, сдача от 80%), экзамен-микс по всем темам, марафон, тренировка по разделам и типам вопросов, работа над ошибками и глоссарий с поиском. После каждого ответа показывается объяснение. Прогресс хранится в браузере (localStorage). Можно поставить на телефон как приложение (PWA).

## Как добавить термины

Откройте [`data/terms.js`](data/terms.js) и добавьте строку в нужный раздел:

```
ТЕРМИН | Расшифровка (или -) | Объяснение простыми словами
```

Вопросы и неправильные варианты ответов сгенерируются сами (берутся из того же раздела и темы). Ручные вопросы лежат в [`data/questions.js`](data/questions.js): первый вариант ответа всегда правильный, при показе варианты перемешиваются.

## Запуск локально

```bash
python3 -m http.server 8000
```

Сборки нет — это статичный сайт (HTML + JS + CSS).
